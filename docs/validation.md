# KantokuAI — テストと検証

[READMEへ戻る](../README.md) · [開発で考えたこと（詳細）](decisions.md)

## テストの規模

| 対象 | テスト | 主に確かめていること |
| --- | ---: | --- |
| iOS（Swift） | 約1,100件（XCTest・Swift Testing） | 出典と記憶の扱い、台本の部分修正、会話の保存と復旧、録画の時間範囲、字幕、書き出し、プレビューの停止と終了待ち |
| サーバー（Python） | 約460件（pytest） | 認証と所有者の確認、利用量と課金、非同期ジョブ、AIの出力の検査、文字起こしと時刻の対応 |

件数は2026年10月時点のテスト関数の数です。

## 自動で実行している検査（GitHub Actions）

mainへの変更やPRのたびに、次のワークフローが動きます。2026年10月4日のmainでは、すべて成功しています。

| ワークフロー | 内容 |
| --- | --- |
| Backend CI | サーバーのテスト（pytest）、CI用スクリプトのテスト、依存パッケージの脆弱性検査（pip-audit） |
| iOS CI | セキュリティと個人情報に関わるテスト（サーバーとの通信の安全性、診断ログ、通知の内容、Webからの取り込み、環境設定、プロフィールの保存） |
| Secret scan | 秘密情報がコミットに含まれていないかの検査 |
| Development Delivery | mainでBackend CIが成功したときに、開発環境のサーバーへ反映 |

## 実機での確認と計測

- **開発版での確認**：変更は開発用のアプリとサーバーに反映し、iPhoneの実機で動作を確かめてから本番へ進めます。
- **工程ごとの時間の記録**：自動編集の各工程の時間を端末に記録し、Macに取り出して一覧にできるようにしています。待ち時間の改善は、この記録で前後を比べています（[詳細](decisions.md#6-待ち時間は測ってから減らす)）。
- **完成動画の照合**：字幕のずれを調べたときは、完成動画のフレームの文字認識と、元動画との音声の波形照合で、字幕と音声の位置を確かめました（[詳細](decisions.md#3-字幕が最大10秒ずれる不具合を完成動画を測って直した)）。
- **方式の比較**：音声認識の方式を変える前に、同じ録音で処理時間と出力を比べました（[詳細](decisions.md#1-速さより本人の言葉を変えない文字起こしを選んだ)）。

## まだ確かめられていないこと

- 自分以外の利用者による、制作時間の短縮などの効果
- 想定しうるすべての通信失敗・中断のタイミングでの復旧
- 本番環境の権限設定とデータの保存期間、外部AIの提供元でのデータ保持の設定
- Android版とiOS版の機能の同等性

本体のソース、テスト、詳しい記録は非公開です。このリポジトリのIssue・PR・コミットは、説明資料の作成と更新の履歴です。
